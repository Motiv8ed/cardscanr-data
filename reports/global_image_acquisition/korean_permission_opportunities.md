# Korean image / metadata permission opportunities

Generated during isolated global-image-acq worktree session.

## Principle

TCGdex (and similar) metadata access ≠ Pokémon artwork rights. Do not download
restricted artwork or assume a metadata licence covers images.

## Opportunities (ranked)

1. **TCGdex KO metadata (in progress)** — public API set/card lists. Metadata-only
   acquisition started on this branch. Image URLs, when present, need per-host
   rights classification before staging.
2. **Official Pokémon Korea / The Pokémon Company** — written enquiry for
   catalogue metadata clarification and any press/promo image terms. Highest
   legitimacy for promo assets; unlikely to grant full-set scan rights.
3. **Korean licensed app/partners** (if any publish terms allowing collector-facing
   metadata reuse) — review terms case-by-case; no scraping behind login.
4. **Collector contribution programme** — written contributor licence + attestation;
   Pokémon IP still required before production promotion.
5. **PokéCardex** — out of scope (CN permission only; no KO region).

## Explicitly rejected

- Marketplace / blog / Discord scrape
- Purchased subscription dumps without licence to redistribute metadata/images
- Hotlinking any third-party scan CDN
